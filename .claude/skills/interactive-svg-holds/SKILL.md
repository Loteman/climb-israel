# איורים אינטראקטיביים ב-SVG (כולל אחיזות טיפוס)

מטרת הסקיל: לבנות גרפיקה כ-SVG inline במקום קובצי תמונה - כך שהיא קלת משקל, חדה בכל רזולוציה, וניתנת לעיצוב/אנימציה/אינטראקציה עם CSS ו-JS רגילים.

## למה SVG ולא PNG/JPG כאן

- SVG הוא טקסט (XML) - קובץ של אייקון פשוט יכול לשקול כמה מאות בייטים במקום עשרות/מאות KB של תמונה.
- חד ב-100% מהרזולוציות (retina, זום) בלי צורך ב-`@2x`/`@3x`.
- ניתן לצבוע, להנפיש ולהגיב לאינטראקציה (hover, click) דרך CSS/JS ישירות - PNG לא מאפשר את זה.
- מתאים במיוחד לסטים של אייקונים חוזרים (כמו סוגי אחיזות טיפוס) שבהם כל אחד הוא וריאציה גיאומטרית פשוטה.

## מבנה בסיסי

```html
<svg viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg" role="img" aria-label="אחיזת Crimp">
  <title>Crimp</title>
  <path d="..." fill="currentColor" />
</svg>
```

- השתמש תמיד ב-`viewBox` (לא ב-`width`/`height` קבועים) כדי שה-SVG יתאים את עצמו לגודל הקונטיינר.
- `fill="currentColor"` מאפשר לצבוע את האייקון דרך `color` ב-CSS - שימושי למצב כהה/בהיר.
- הוסף `role="img"` ו-`aria-label`/`<title>` לנגישות - קורא מסך צריך לדעת מה זו הצורה.
- שמור על נקודות path פשוטות ומספר מינימלי של nodes - path מסורבל מכביד גם כ-SVG.

## סוגי אחיזות טיפוס נפוצים (לרפרנס ויזואלי)

| אחיזה | תיאור צורה | רמז לציור |
|---|---|---|
| **Jug** | אחיזה גדולה ועגולה, קלה לאחיזה | עיגול/אליפסה גדולה עם "שפה" תחתונה בולטת |
| **Crimp** | שקע קטן וצר, נאחזים בקצות האצבעות | מלבן דק וארוך עם קצה חד |
| **Sloper** | משטח משופע וחלק, בלי שקע ברור | קשת עדינה גדולה, כמעט "כיפה" שטוחה |
| **Pinch** | שני צדדים שנצבטים בין אגודל לאצבעות | שני "פרוטרוזיות" מנוגדות עם רווח צר ביניהן |
| **Pocket** | חור צר ל-1-2 אצבעות | עיגול קטן חלול בתוך צורה גדולה יותר |

כשמציירים סט של אייקונים כאלו, שמור על אותה סגנון קו/עובי ופלטת צבעים בין כולם - זה מה שגורם לזה להרגיש כמו סט עקבי ולא כמה איורים מקריים.

## אינטראקטיביות

```css
.hold-icon {
  transition: transform 200ms ease, fill 200ms ease;
  cursor: pointer;
}
.hold-icon:hover {
  transform: scale(1.08);
}
```

- להנפשה בתוך ה-SVG עצמו (למשל "רעידה" קלה בהובר), אפשר להשתמש ב-CSS על אלמנטים בתוך ה-SVG בדיוק כמו על HTML רגיל - אין צורך ב-SMIL (`<animate>`) לרוב המקרים הפשוטים.
- כשה-SVG לחיץ (בוחרים סוג אחיזה מתוך רשימה), עטוף אותו ב-`<button>` או הוסף `tabindex="0"` + `role="button"` אם הוא לא בתוך אלמנט לחיץ טבעי, כדי שינווט גם מהמקלדת.

## מתי כן להשתמש בתמונה רגילה

תמונה/וידאו אמיתיים (תמונת אולם, וידאו של מטפס) לא צריכים להפוך ל-SVG - זה מתאים רק לצורות גרפיות/אייקוניות, לא לתוכן פוטוגרפי.
