# איסוף מידע לאתר טיפוס/בולדרינג

מטרת הסקיל: להביא מידע עדכני ואמין מהאינטרנט על עולם הטיפוס/בולדרינג בישראל, ולהפוך אותו לתוכן שאפשר להשתמש בו באתר - בלי להעתיק טקסט מוגן זכויות יוצרים כלשונו.

## איך למשוך מידע

- השתמש בכלי `WebSearch`/`WebFetch` (או כלי גלישה, אם זמין) כדי לאתר ולקרוא דפים רלוונטיים - אתרי אולמות בולדרינג, מגזינים ישראליים לספורט חוץ/טיפוס, חנויות ציוד טיפוס.
- כשהמידע רגיש לזמן (שעות פתיחה, מחירים, כתובות), ציין תמיד בתוצאה **מתי** המידע נשלף, כדי שהמשתמש ידע כמה הוא טרי - מידע כזה משתנה בלי אזהרה.
- כבד את מדיניות האתר: אם דף חוסם גישה (robots.txt, כפתור "אני לא רובוט", paywall), אל תעקוף - דווח למשתמש שהמידע לא נגיש אוטומטית ותציע לו לבדוק ידנית.

## מבנה נתונים לאולמות בולדרינג

כשמרכזים מידע על אולם/מקום, ארגן אותו כ-JSON עקבי כדי שיהיה קל להטמיע באתר (כרטיס מקום, מפה, Schema.org - ראה סקיל `seo-hebrew-optimizer`):

```json
{
  "name": "שם האולם",
  "address": "כתובת מלאה",
  "city": "עיר",
  "hours": {
    "sunday": "09:00-23:00",
    "monday": "09:00-23:00",
    "friday": "09:00-15:00",
    "saturday": "סגור"
  },
  "phone": "",
  "website": "",
  "how_to_get_there": "תיאור קצר - חניה, תחבורה ציבורית, כניסה",
  "source_url": "מאיפה נשלף המידע",
  "fetched_at": "תאריך השליפה, פורמט YYYY-MM-DD"
}
```

## כתבות וטרנדים

- כשמסכמים כתבה חיצונית (טרנד במוצרים, סיקור אירוע), **סכם במילים שלך** - אל תעתיק פסקאות כלשונן. מותר ציטוט קצר אחד (עד כ-15 מילים) עם ציון מקור, בהתאם למדיניות זכויות היוצרים.
- ציין תמיד קישור למקור המקורי כדי שהמשתמש יוכל לבדוק ולתת קרדיט.
- כשמשווים כמה מקורות (למשל "מה הטרנד החם בנעלי טיפוס"), ציין אם המקורות מסכימים או סותרים - אל תציג דעה בודדת כעובדה מוסכמת.

## תדירות רענון

מידע כמו שעות פתיחה ומחירים משתנה - הצע למשתמש לרענן אותו מדי כמה חודשים, ולא להסתמך על נתון ששלפת פעם אחת ולשכוח ממנו. אם יש לאתר עמוד "עדכון אחרון" (last updated), ציין את התאריך הזה גם באתר עצמו ליד המידע.
