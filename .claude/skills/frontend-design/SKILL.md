# עיצוב Frontend מודרני

מטרת הסקיל: לוודא שכל ממשק שנבנה נראה מקצועי ועדכני מהצעד הראשון, ולא "עוד HTML לבן עם קופסאות אפורות". השתמש בעקרונות הבאים כברירת מחדל, גם אם המשתמש לא פירט אותם.

## 1. Glassmorphism (זכוכית מטושטשת)

שימושי לכרטיסים, ניווט צף (navbar), מודאלים ופאנלים מעל רקע עם תוכן/תמונה.

```css
.glass {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.15);
  border-radius: 16px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.2);
}
```

- אל תשתמש בזה בכל מקום - זה אפקט חזק, נכון בעיקר לאלמנטים "צפים" מעל רקע (hero, מודאל, navbar sticky).
- ודא ניגודיות טקסט מספקת מעל הזכוכית (ראה סעיף 3) - שקיפות גבוהה מדי הופכת טקסט לבלתי קריא.

## 2. Responsive Grid

עבוד Mobile-first: כתוב קודם את הפריסה לנייד, והרחב עם `min-width` media queries או עם Tailwind `sm:` `md:` `lg:`.

- השתמש ב-CSS Grid לפריסות דו-ממדיות (גלריות, דשבורדים) וב-Flexbox לשורות/עמודות חד-ממדיות.
- העדף `grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))` על פני breakpoints קשיחים כשהתוכן חוזר על עצמו (כרטיסים, מוצרים).
- לגדלי טקסט ורווחים שמתכווננים חלק בין breakpoints, השתמש ב-`clamp(min, preferred, max)` במקום כמה media queries נפרדות.

## 3. טיפוגרפיה וניגודיות צבעים

- הגדר סקאלת טיפוגרפיה עקבית (למשל 4-6 גדלים: h1, h2, h3, body, small) במקום גדלים אקראיים.
- שמור על יחס ניגודיות (contrast ratio) של לפחות 4.5:1 לטקסט רגיל ו-3:1 לטקסט גדול, לפי WCAG AA. בדוק זאת במיוחד כשמשתמשים ב-Glassmorphism או ברקעים בהירים/כהים מעורבים.
- הגדר את הצבעים כמשתני CSS ב-`:root` כדי שיהיה קל לתחזק ולתמוך במצב כהה.

## 4. מצב כהה (Dark Mode)

```css
:root {
  --bg: #ffffff;
  --text: #111111;
}
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0b0b0f;
    --text: #f2f2f2;
  }
}
```

- אם באתר יש מתג ידני להחלפת מצב, הוסף גם `[data-theme="dark"]` שדורס את ה-media query, ושמור את הבחירה ב-localStorage.
- אל תשתמש בשחור מלא (#000) או לבן מלא (#fff) לרקעים - גוונים קרובים (למשל #0b0b0f, #f7f7f8) נראים פחות מעייפים לעין.

## 5. הנפשות CSS נקיות

- הנפש רק `transform` ו-`opacity` - אלו התכונות היחידות שה-browser יכול להאיץ ב-GPU בלי לגרום ל-layout reflow ולקפיצות (jank).
- משך הנפשה סביר: 150-300ms למיקרו-אינטראקציות (hover, כפתורים), 300-500ms למעברי עמוד/מודאלים.
- השתמש ב-easing טבעי כמו `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-expo) במקום `linear`.
- כבד `prefers-reduced-motion` - בטל או צמצם הנפשות למשתמשים שביקשו זאת:

```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

## סדר עבודה מומלץ

1. הגדר את משתני הצבע/טיפוגרפיה ב-`:root` (כולל גרסת dark mode).
2. בנה את הפריסה הרספונסיבית (mobile-first).
3. הוסף אפקטים ויזואליים (glass, צללים, גרדיאנטים) רק אחרי שהמבנה הבסיסי עובד.
4. הוסף הנפשות בסוף, ובעדינות.
